## 2. 改造目标

1. 学习中心从「左导航 248 + 窄内容区」改为「**固定侧栏 240 + 内容区 flex:1（min-width 720）**」。
2. 四个页面（概览 / 课程 / 考试 / 报告）按 v40 设计令牌重做，**新增一页「学习笔记」**，**不新增「学习排行」独立页**（榜单收敛在个人中心）。
3. **后端只动一处**：`NotePageVO` 补 `courseId` / `sectionId` / `courseName` 三个字段（见 §6.5 的硬伤说明）——这不是新接口，是给现有 VO 补字段；除此之外**不动后端、不加接口**，所有新模块必须用现有接口的真实数据。

## 6. 逐页设计

### 6.1 学习概览

```
下午好，jack                                    2026 / 11 / 21
继续上次的进度
┌ 继续学习 Hero（深蓝卡，8/12 列） ────────┐ ┌ 最近一次考试 4/12 ───┐
│ 继续学习 / 课程名                        │ │ 82 分 正确率 76%     │
│ [上次学到] 第 1 节 第一章 带你玩-第1课   │ │ 课程1 · 第 2 章 索引 │
│ ──进度条 42%── 已学 5/12 · 还剩 7 节     │ │ 最近 7 次柱状        │
│                            [继续学习 →]  │ │ 全部考试 →           │
└──────────────────────────────────────────┘ └──────────────────────┘
01 本周节奏   最近 7 天完成的小节（右侧不放数字 —— 周进度只在侧栏目标卡，见下方规则）
02 在学课程   3 张卡 + 「去选一门新课」格
03 今天要做的  到期课程（≤3 条，来自 /ls/lessons/todo 的 expiring；「计划缺口」不进待办，见下方规则）
04 我的笔记（3 条，带视频时间点）/ 学习排行（名次 + 前三，跳个人中心天梯榜）
05 学习报告（3 个数字 + 30 天迷你柱）+「接下来学」推荐（**仅 0 课程时显示**）
```

- **今日卡已删除**：今日积分 / 连续打卡进了侧栏目标卡，不再重复。
- **周进度数字只允许出现在侧栏目标卡这一处**：问候副文案不写数字；待办里不列「本周计划还差 N 节」；01 段右侧**不放「目标 / 已完成」数字**（mock 里的「目标 1 节 · 已完成 0 节」是旧版残留，以本规则为准）。
- **待办的类型只有「到期课程」**：todo 接口的 planGap（计划缺口）不再进待办 —— 那是周进度的第二种说法，出现即违反上一条。所谓「待复盘考试」本期不做（需要 exam 数据聚合定义口径，§11 精神）。
- **选课入口只留一个**：02 段的「去选一门新课」格常驻；「接下来学」推荐只在 `lessons.length === 0` 的空态里出现，有课用户不再给第二个推荐入口。
- 「本周节奏」本周 0 节时走紧凑空态（一行提示 + 去学习按钮），不画空柱。
- 每个模块**独立请求、独立三态**，父级不做编排（项目既有约定）。

### 6.2 我的课程

页头（在学 N 门 · 已学完 N 门 · 共 N 节已学）+ 搜索框（前端过滤）+ 排序（最近学习 / 即将到期）+ 三个状态胶囊（在学 / 已学完 / 已失效，带计数）+ 3 列卡片网格。
卡片：封面 16:9 + 状态标签（学习中 / 已学完 / 未开始 / 已失效）+ 课程名 + 有效期 +「已学 N / M 节 · 还剩 K 节」+ 进度条 + 双按钮（继续学习 / 计划）。
筛选状态落 URL query（`?tab=finished`）。

### 6.3 我的考试

3 个统计头（考试总数 / 平均分 / 最高分，从全量 100 条算）+ 表格（课程 / 小节 / 得分 / 正确率 / 用时 / 交卷时间 / 操作）+ 前端分页 + 点击行看解析。
得分及格线**按 score / totalScore ≥ 60% 判定**（练习卷满分可能是 10 分，写死「≥60 分」会把小分卷全染绿）；绿色及格、红色不及格。

### 6.4 学习报告

30 / 90 天切换（落 URL query）+ 4 个 KPI（累计学习 / 活跃天数 / 完成课程 / 考试均分）
+ 01 学习活跃度（按天热力图，列=周，格子 26px；右侧统计卡 2×2 排布：区间完成 / 日均 / 最长连续 / 活跃率）
+ 02 周目标达成（最近 4 周条 + 达标数）
+ 03 考试分数趋势（最近 8 次柱状 + 均分虚线 + 均分/最高/最近）
+ 04 课程投入分布（按已学小节排序，前 6 门）。

### 6.5 学习笔记（新增页）

页头「学习笔记」+ 副标（共 N 条）+ 「我的笔记 / 全部笔记」切换 + 列表（复用 `src/components/ui/NoteCard.vue`，含作者、时间、视频时间点）+ 分页。

**回跳能力：本档已拍板走方案 a（后端补字段），笔记页直接开「回到这一节」**（背景见 §10.4）：

- 后端改动（唯一一处）：`NotePageVO` 加 `courseId` / `sectionId` / `courseName` 三个字段，service 里 `BeanUtils.copyProperties` 会自动带上（`LearningNote` po 本来就有），约 3 行。
- 前端按有字段实现：列表项显示课程名（小字），点击 → `/learning/index?id={courseId}&sectionId={sectionId}`（只能到小节，到不了秒，见 §10.5）。
- **兜底**：接口若返回空字段（后端没部署新 jar），列表项隐藏课程名、点击不跳 —— 不报错、不渲染死链接。

### 6.6 侧栏签到按钮

| 项 | 规格 |
|---|---|
| 归属 | 侧栏底部、目标卡下方，组件 `SidebarSign.vue`（`studyShell.vue` 内引用，不在页面里） |
| 数据 | 读 `useClassOverview` 的 `signData` / `signReady` / `streakDays`，不发请求 |
| 已签到判定 | `signData[dayjs().date() - 1] === 1`（数组索引 0 = 1 号）→ 按钮置灰为「今日已签到」 |
| 未就绪 | `signReady === false` 时按钮可点但文案保持「签到」，点了按失败处理，不假装成功 |
| 点击 | `POST /ls/sign-records`；成功后 `ElMessage.success`，再 `await loadSignAndPoints()` 刷新点阵 / 连续 / 今日积分 |
| 失败 | `ElMessage.error(errMsg(res,'签到失败'))`，按钮回可点态 |
| 文案 | **不写死「+N 积分」**。接口不返回本次得分就只写「签到」；后端返回了再显示 |
| 上限说明 | 签到积分上限由后端 `PointsRecordType.SIGN` 决定，前端不参与计算 |

## 9. 项目既有约定（不遵守会出 bug）

1. **三态**：每个数据模块自己维护 `loading / ok / error`，失败用 `InlineError` 展示并带重试，**父级不统一编排**。
2. **禁止重复请求**：同屏多个组件要用的账号级数据（本周计划 / 打卡 / 今日积分）走 `useClassOverview` 单例；「最近学习」走 `utils/nowLesson.js`（5s TTL + in-flight 合并）。组件里禁止各自打一遍。
3. **错误文案**：用 `errMsg(res)` / `catchMsg(err)`，**不要写 `res.data.msg`**（业务失败时响应体没有 `data`）。
4. **网关「服务不存在」** 返回 `HTTP 200 + {code:0}`：按空态处理，不要当错误弹窗。
5. **数据封顶**：`learnedSections` 可能大于 `sections`，展示前必须 `Math.min`，否则进度条溢出、文字变成「已学 21 / 12」。
6. **不编数据**：拿不到就显示 `-` 或空态，不要先摆 0。
7. **样式**：`<style lang="scss" scoped>`，只用 v40 令牌；不要引入新的 `--color-*` 用法。
8. **导航**：由 `route.matched[1].children` 派生，`hidden` 不上导航；链接用 `{ name }` 而不是相对 `path`（相对路径会被当前路由父级拼接出错）。

## 10. 已知待修的问题

1. **本周节奏的柱与统计不是同一个数**：柱子画 `summary.daily[].sections`，右侧统计读 `plans.weekFinished`。统一成同一来源（建议都用 `summary`），否则出现「柱子 3 节、统计 2 节」。
2. **同一个数字同屏出现多次**（数据源统一解决不了，这是信息架构问题）：上一版是「问候副文案 + 侧栏 0/1 + 待办」，这一版仍有风险。规则写死在 §6.1：**周进度数字只在侧栏目标卡出现一次**，问候文案、待办、01 段右侧都不再带这个数。
3. **「连续打卡」是月内连续**（从当月末尾往前数，跨月断），文案写「本月连续」。
4. **笔记 VO 缺回跳字段（已拍板走方案 a）**：`NotePageVO` 没有 `courseId / sectionId / courseName`，`notes.vue` 的 `openNote` 现在静默 `return`。处理：后端补 3 个字段（`LearningNote` po 已有，VO 加字段 + copyProperties，约 3 行）；前端笔记页直接按「有字段」实现回跳，并对空字段做兜底（隐藏课程名、不渲染跳转）。不要做成 a/b 两可让执行者选。
5. **笔记到不了秒**：即使补了字段，播放页只读 `query.sectionId`，不读 `noteMoment`。要精确到秒得给 `/learning/index` 加 `t` 参数（本次范围外）。

## 11. 明确不做

- **学习时长**：无接口，首页的「X 小时」是 `积分×6 + 完成节×24` 估的，学习中心不写这种假数据。
- **证书墙 / 错题本 / 跨年热力图**：都需要后端新接口。
- **学习排行独立页**：与个人中心「学霸天梯榜」重复，已删除；概览只留名次摘要卡，跳转 `{ name: 'myIntegralRanking' }`。
- **侧栏的考试数 / 笔记数**：需要额外请求，默认不做。只保留「在学课程数」（`courseCount` 单例已有，零额外请求）。如果要显示，在壳里并发拉 `total` 即可，但要接受 2 个额外请求。
